# Rayansh Fashion

Premium kurtis e-commerce shop built with React + Vite + Tailwind CSS.

## Features

- Customer shop: Home, Shop, Product detail, Bag, Checkout
- Order confirmation with WhatsApp message
- Admin panel (open from footer)
  - PIN: **9689**
  - View & update orders
  - Manage products (show/hide)
  - Shop settings (name, WhatsApp, city, UPI)
- Data stored in browser localStorage (easy to upgrade to Neon later)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy on Vercel

1. Go to [vercel.com](https://vercel.com) → Add New Project
2. Import `dineshsatelkar-11/Ecommerce-`
3. Deploy (no environment variables needed)
